Slop stops here.

Point slopcop at a public GitHub repository. Files are fetched straight from GitHub and scanned by the real linter compiled to WebAssembly. Nothing leaves your browser.

Try

GitHub token (optional)

Without a token, every scan from your network shares GitHub's anonymous limit of 60 API requests per hour, and each scan uses two. A token raises the limit to 5,000 per hour. Create a fine-grained token with public repository access and no permissions. It stays in this tab and is only sent to api.github.com.
